# Notebooks

Executed and clean reproduction notebooks should be added here only from the real research environment.

Recommended split:

- `Gemma2_Reproduction.ipynb` — clean smoke-first reproduction launcher;
- `Interpretability_Extension.ipynb` — prospective cross-model launcher;
- executed notebooks stored separately under `replication/evidence/<run>/` so outputs are preserved without confusing them with clean launchers.

Notebook payloads should record the repository commit, model/SAE revisions, precision, seed, and schedule hash.
